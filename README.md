
# Agriculture Data Analysis Project

## Project Overview
This project focuses on analyzing agricultural data using Python, Excel, and Power BI.

## Tools and Technologies
- Microsoft Excel
- Python
- Pandas
- NumPy
- Power BI

## Project Workflow

1. Created raw agricultural data using Excel.
2. Cleaned and processed raw data using Python.
3. Used Pandas for data cleaning.
4. Exported the cleaned data into Excel.
5. Imported cleaned data into Power BI.
6. Created an interactive dashboard for data analysis.

## Project Files

- 01_Raw_Data: Original agricultural dataset.
- 02_Cleaned_Data: Cleaned Excel datasets.
- 03_Python_Code: Python data cleaning script.
- 04_PowerBI_Dashboard: Power BI dashboard.
- 05_Dashboard_Screenshots: Dashboard images.
